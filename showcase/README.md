# Showcase kit

Everything for the table: posters, the monitor loop, stall decoration, the tester sign-up sheet, and the demo script. The ready-to-print files are in `out/`.

All PDFs are vector, so A4 files print sharp at A3: choose paper size A3 and "Fit to page". Home printers leave a white margin around the full-width green bands; a print shop can print edge to edge.

**Cost advice:** if you only pay for one upgrade, make poster 1 A3 colour. Everything else works at A4, and the sign-up sheet, table tent and tester poster work in black and white.

## The monitor loop

Open `slides/index.html` in Chrome on the laptop, drag the window to the monitor, press **F** for full screen. It moves on every 8 s and loops (8 slides, about a minute). Arrow keys or a click step through; **P** pauses. No internet needed: everything is local.

When a judge stops by, mirror the laptop onto the monitor (Cmd+F1) for the live demo, then switch back.

The phone screenshots on the slides come from `assets/app/`. To retake them from the running demo (after a reset, in the daytime so stalls are open):

```bash
python3 showcase/tools/capture_app.py http://localhost:3000
python3 showcase/tools/render.py slides      # rebuild out/slides-NN.png
```

(`render.py` and `capture_app.py` need `pip install playwright`; they use your installed Chrome. `render.py` with no arguments rebuilds every PDF.)

The phone frame is drawn in CSS (burgundy titanium, Dynamic Island cutout), so no Apple template download is needed and it scales sharply.

## Sample MyCamu screenshots

`https://demo.mealdeck.in/demo-mess` (QR on the table tent, link under the import button on the Mess tab, demo only) offers today's two sample screenshots: breakfast + lunch, snacks + dinner, marked DEMO. Visitors save them and use **Mess → Fill from MyCamu screenshots**. They're generated by `tools/make_mess_screens.py` for every weekday; I checked all 7 days through the app's own OCR and parser, and every day reads all four meals as complete.

The import only takes **today's** menu, and its button only shows while a meal is still empty. So reset the demo before judges arrive, and again after someone has filled the menu.

## Play Store and closed testing

There's no Play Store listing yet, so nothing says "on the Play Store". The posters only ask Android users to help test.

Collecting emails is worth it **if** you'll publish to Play in the next few weeks: a personal Google Play developer account made after Nov 2023 has to run a closed test with at least 12 testers opted in for 14 days in a row before it can go public. A showcase table is the easiest place to find 12 people. Check the current rule in Play Console before you rely on that number. If you're not publishing soon, skip poster 4 and the sheet.

After the event, type the Gmails into Play Console → Testing → Closed testing → Testers (an email list). Then shred the sheets, as the sheet promises.
